# 커피 내기 앱 — 디자인 스펙

**Date:** 2026-05-14  
**Status:** Approved

---

## 개요

친구/동료들이 모인 자리에서 "누가 커피 살지"를 결정하는 모바일 웹 앱. 5가지 게임을 제공하며, 모든 게임의 최종 목적은 커피를 사야 할 한 명(또는 여러 명)을 결정하는 것이다.

## 공통 게임 플로우

모든 게임이 동일한 3단계 구조를 따른다:

1. **설정 단계** — 참가자 이름 입력 (이름 태그 추가/삭제, 최소 2명)
2. **실행 단계** — 게임별 애니메이션 진행 (시작 버튼으로 트리거)
3. **결과 단계** — "☕ [이름]이 커피 쏩니다!" 대형 텍스트 표시 + 다시하기 / 홈으로 버튼

---

## 게임별 상세

### 1. 사다리타기 (`/ladder`)

- 참가자 이름을 상단에 배치, 하단에는 "커피" 1개 + 나머지 "안전" 배치
- 세로 선과 랜덤 가로 연결선으로 구성된 사다리 생성
- 시작 시 각 세로 선이 위에서 아래로 순차적으로 하이라이트되며 내려가는 애니메이션
- "커피" 결과에 도달한 선의 참가자가 패자

### 2. 룰렛 (`/roulette`)

- 참가자 이름이 동일 비율로 나뉜 원형 휠로 표시
- 각 칸은 고정 색상 팔레트로 구분
- "돌리기" 버튼 클릭 시 빠르게 회전 후 천천히 멈추는 easing 애니메이션
- 화살표(pointer)가 가리키는 칸의 참가자가 패자
- SVG로 구현 (React에서 상태와 애니메이션 제어가 용이)

### 3. 랜덤 뽑기 (`/random-pick`)

- 참가자 이름이 카드 형태로 뒤집혀 있음 (앞면 숨김)
- "뽑기" 버튼 클릭 시 랜덤 1명의 카드가 뒤집히며 이름 공개
- 카드 뒤집기 flip 애니메이션 사용
- 뽑힌 참가자가 패자

### 4. 숫자 업다운 (`/number-game`)

- 각 참가자가 1~100 사이 숫자를 선택 (다른 사람 선택 전 숨김 처리)
- 모두 선택 완료 후 "공개" 버튼 클릭 시 전체 숫자 동시 공개
- 시스템이 정답 숫자(1~100 랜덤)를 생성, 가장 가까운 사람이 패자
- 동점 시 동점자들만 재게임

### 5. 주사위 (`/dice`)

- "굴리기" 버튼 클릭 시 모든 참가자의 주사위가 동시에 굴러가는 3D 애니메이션
- 결과: 가장 낮은 숫자가 나온 참가자가 패자
- 동점(최저 숫자 동점) 시 해당 참가자들만 재굴리기

## 디자인 시스템

### 색상

| 역할 | 값 |
|------|-----|
| 배경 | `#f5f5f5` |
| 헤더 | `#111111` |
| 헤더 텍스트 | `#ffffff` |
| 강조 (버튼, 결과) | `#ff3b30` |
| 카드 배경 | `#ffffff` |
| 아이콘 박스 | `#111111` |
| 보조 텍스트 | `#999999` |
| 그림자 | `rgba(0,0,0,0.08)` |

### 타이포그래피

- 헤드라인: `font-weight: 900`, `letter-spacing: -1.5px`
- 본문: `font-weight: 400~600`
- 폰트: 시스템 폰트 (`-apple-system, BlinkMacSystemFont, sans-serif`)

### 레이아웃

- 모바일 우선, 기준 너비 `390px`
- 최대 너비 `480px` (데스크탑에서도 모바일 카드 형태 유지)
- 페이지 상단 블랙 헤더 → 콘텐츠 영역 `#f5f5f5` 배경
- 카드: `border-radius: 12px`, 흰 배경, 연한 그림자

### 공통 컴포넌트

- `GameHeader` — 게임 제목 + 홈으로 돌아가기 버튼
- `ParticipantInput` — 참가자 이름 입력 + 태그 추가/삭제 UI
- `StartButton` — 빨간 대형 버튼 ("시작하기" / "돌리기" 등)
- `ResultScreen` — "☕ [이름]이 커피 쏩니다!" + 다시하기 버튼

## 비기능 요구사항

- 모든 애니메이션은 `prefers-reduced-motion` 미디어 쿼리 존중
- 결과 발표 순간에 최대한 임팩트 있는 연출 (대형 텍스트, 컬러 강조)
- 게임 시작 전 최소 참가자 수 검증 (2명 미만 시 시작 불가)
- 동점 처리 명확하게 (숫자 업다운, 주사위)
